## Python n body simulation using Pygame and Numpy
Made as 11th grade student project.  
  
  
#Controls  
1/2/3 to switch presets   
Space to (un)pause  
Left/right arrow keys to slow down/speed up (this will make the sim more/less accurate)  
Scroll wheel to zoom  
Left click on a body to follow it, click on empty space to reset  

  
#UI currently shows  
Time accumulated since start  
Current simulation speed  
FPS
Currently available presets and their hotkeys  
How much energy has been lost or gained since the start(the error)  
  
#Other details  
Requires Python with the libraries Pygame and NumPy.  
To use the simulation, simply run [nbodysim.py](nbodysim.py)
